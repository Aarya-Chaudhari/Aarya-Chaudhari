## 💭 Questions I'm Exploring

I'm increasingly interested in questions that go beyond simply making AI systems work.

### Interpretability

**When a model explains its own behavior, how do we know that explanation corresponds to the computation that actually produced the behavior?**

### Reliability

**How stable are learned behaviors when models encounter distribution shifts, adversarial prompts, or unfamiliar tasks?**

### Self-Monitoring

**Can AI systems reliably detect changes in their own behavior before those changes become visible through failures?**

### Agentic AI

**How should increasingly autonomous AI agents behave when objectives, context, tools, and instructions conflict?**

These questions are currently shaping the direction of my AI/ML learning and research.
